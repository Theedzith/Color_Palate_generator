# Color Palette Generator

A responsive, lightweight web app that generates random 5-color palettes. Click **Generate Palette** to get a fresh set of colors, or click any color box to copy its hex code to your clipboard.

## Features

- Generate a random 5-color palette with one click
- Copy any color's hex code to the clipboard with a click
- Visual "copied" confirmation feedback
- Fully responsive layout that works on mobile and desktop
- Clean, modern UI with a gradient background

## How to Use

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Theedzith/Color_Palate_generator.git
   cd Color_Palate_generator
   ```
2. Open `index.html` in your web browser:
   ```bash
   open index.html
   ```
3. Click the **Generate Palette** button to create a new random palette.
4. Click the copy icon (or the color box itself) to copy the hex code to your clipboard.
